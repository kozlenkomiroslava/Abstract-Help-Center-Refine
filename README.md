**Abstract Help Center**

A frontend recreation of the Abstract Help Center page, built as a practice project to improve HTML, CSS, SCSS and a little bit of JS skills.

*Features*
Responsive help center layout
Navigation header with buttons
Search section
Feature cards with illustrations(grid template)
Links to relevant help pages
SCSS for organized styling

*Technologies*
HTML5
SCSS
CSS
JavaScript


This project was created as a frontend practice project based on the Abstract Help Center design.

The goal was to practice building a page from an existing design while improving layout, styling, responsive design, and code organization.

*Getting Started*

Clone the repository:

git clone https://github.com/kozlenkomiroslava/Abstract-Help-Center-Refine.git

Open the project in VS Code and run the Sass compiler:

npm install
npm run sass

Then open index.html in your browser.
